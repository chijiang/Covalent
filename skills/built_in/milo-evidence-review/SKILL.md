# Evidence review from supplied material

Identify the question and what evidence would answer it. Read accessible supplied files or workspace material with the appropriate tool. Keep a short source map: source or file, relevant passage or location, date if known, and what it directly supports.

Distinguish direct evidence, user report, inference, and open question. If two sources disagree, show the exact point of conflict and what could resolve it. For changing facts, identify the date of the available material and say when a current check is still needed.

Do not invent citations, imply that a URL has been opened when it has not, or treat an unexamined attachment as read. If access is missing, work from what the user provided and explain the limit. See `references/source-check.md` with `read_skill_resource` for a compact source checklist.
