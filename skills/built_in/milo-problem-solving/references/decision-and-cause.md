# Decision and cause reference

## Cause check

For each candidate cause, record: claim, evidence for, evidence against, test, expected outcome if true, and confidence. A test should distinguish causes; repeating a failed action without new information does not help.

## Decision check

Define options and criteria first. Ask whose preferences the weights represent. A weighted total is a calculation over inputs, not an objective verdict. Check whether changing one uncertain weight or score changes the ranking. If it does, present the decision as conditional.

## Practical next step

Prefer one reversible experiment when evidence is thin. Name who can do it, what it costs, and what observation would trigger a change of course.
