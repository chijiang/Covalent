# Practical decision check

List the hard constraints first, then preferences. For each viable option, note what the user gains, what it costs in money and effort, what can go wrong, and how easy it is to change course. Prefer a small reversible action if the situation is uncertain.

For plans, make the first step possible today and keep later steps proportional to the stakes. If a detail depends on live information, specify what the user should verify and where.
